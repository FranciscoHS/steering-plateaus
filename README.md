# Steering Activation Plateaus

Research project investigating steering activation plateaus in GPT-2.

## Structure

- `notebooks/` - Exploration and Colab migrations
- `src/` - Cleaned-up reusable code
- `scripts/` - Experiment runners
- `results/` - Outputs, plots, checkpoints
- `writeup/` - Paper drafts and figures

## Setup

```bash
pip install -r requirements.txt
```

## RunPod

Sync scripts are in the project root:
- `./sync_to_runpod.sh` - Upload code (excludes results/)
- `./sync_from_runpod.sh` - Download results and checkpoints
